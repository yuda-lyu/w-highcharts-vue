genComponent(name, Highcharts) → {Object}

Description:

  • 產生Highcharts繪圖組件(Vue2)，取代vue-highcharts之genComponent

    options變更時之更新方式由prop updateMode決定： 'rebuild'(預設)：options變更即銷毀並重建整張圖(同vue-highcharts與本套件1.0.18之行為)，同一份設定恆畫出同一張圖，不受先前設定與使用者操作影響；縮放、導覽列範圍、圖例顯隱、點選取、tooltip等互動狀態隨之重置； 'update'：以chart.update(options, true, true)就地更新，保留縮放、導覽列範圍、圖例隱藏，但Highcharts之update與新建並不等價，結果可能與新建不同(見下列〈chart.update之已知狀況與問題〉)，不保證等同重建； 兩種模式皆為：內容相同之新物件(例如模板物件字面值於每次重繪產生者)不視為變更；掛載時建立圖表，銷毀時destroy

    為何預設重建(1.0.23~1.0.29曾改為預設就地更新，其後恢復)： 就地更新使「同一份設定畫出之圖」隨圖先前之設定與操作而異，下游e2e標準圖與規格(同設定同圖)因此失效(Gitea #33)；其中一類差異(下列第2點)出自Highcharts自身，無任何選項層之補丁能消除，只有重建能與新建等同； 重建亦不慢於就地更新(實測5系列×2000點，Highcharts每次約26ms對45ms)；就地更新所保留之互動狀態僅縮放、導覽列範圍、圖例隱藏三類，點選取與tooltip懸停反正不保留； 需保留該三類互動狀態者(例如資料持續推播而使用者正在檢視縮放範圍)可自行給updateMode為'update'，並自行承擔下列差異

    〈chart.update之已知狀況與問題〉(Highcharts 11.4.8實測；行號為node_modules/highcharts/highstock.src.js，核心區段與highcharts.src.js相同；重現證據見sgud/exp/experience.md)：

    1. 合併而非取代：Chart.update先diffObjects(新設定, chart.options)(:37593)，再merge進userOptions(:37594)，軸為Axis.update之merge(this.userOptions, options)(:21392，原碼JSDoc :21373-21374明寫only new or altered options need to be specified)； 新設定省略之鍵(min、max、tickInterval、tickAmount、softMax、marginLeft、plotLines…)沿用舊值，只有顯式undefined可覆寫(:412-414)，預設值非undefined之鍵(例如lineWidth)連此法也無法還原； 後果：設定A有yAxis.max為3、設定B省略，更新後軸上限仍為3(w-geo-vue切換參數時同一圖元件被餵入不同設定即屬此類)；官方issue #14969亦答覆不合併之更新唯一做法是重建
    2. 刻度間隔可能與新建不同：新建由Chart.render(:36979-37054)以扣除x軸標籤預留空間後之縮減軸長首算刻度，更新由Chart.redraw(:35779、setScale :35848-35851)以保留之最終軸長(len屬Axis.keepProps，:21472-21481)計算； 與設定內容無關，連只改系列名稱或只改資料都可能發生，此為Highcharts自身之update與new不等價，無選項層修法；後果：同設定同尺寸下y軸刻度間隔與範圍不同(實測±200/間距100對±150/間距50)
    3. Axis.keepProps殘留使用者範圍：userMin、userMax、len等於更新後保留(:21472-21481)，且hardMin = pick(axis.userMin, options.min)(:19520)使userMin優先於新設定之min；Highstock之navigator於資料更新時亦會寫入baseXAxis.userMin/userMax(:50014-50018)； 後果：使用者縮放過後，新設定明確給的xAxis.min、max仍被舊縮放範圍蓋過
    4. Highstock開navigator時強制之startOnTick、endOnTick為false(getForcedAxisOptions :53535-53551)及Stock預設值(:53596-53630)只在建圖(StockChart.init :53640)與createAxis(:53660)時套用，更新不重套； 使用端設定帶startOnTick為true者，因diffObjects把true與chart.options內被強制之false視為變更而套用true，第一次更新(即使只差資料)即失效；後果：拖導覽列把手與滾輪縮放之起迄被捨入至刻度，不能選取精確時間
    5. navigator、scrollbar開關切換：Navigator.update(:49042-49053)關閉時不移除chart.navigator與chart.scrollbar，其getMargins監聽(:50097-50108)恆加navigator.margin(25)，繪圖區變矮、刻度改變； 無navigator建圖後更新為啟用則chart.navigator為null，導覽列根本不出現(marginBottom卻已加大)
    6. 格線群組排到圖框之後：Axis.update銷毀並重建格線群組(:21223-21230、:20722-20736)，zIndex(皆為1)相同時插在既有元素之後(:11056-11064)，圖框於drawChartBox(:36846-36853)以zIndex為1建立，新建時先於格線群組； 每一次chart.update皆發生，與設定內容無關(含僅改資料)；後果：淡色格線蓋在plotBorderColor之圖框上，圖框上緣與右緣由深色變淺色
    7. 互動狀態：保留縮放(含框選縮放與重設縮放按鈕)、navigator範圍、圖例隱藏；不保留點選取(allowPointSelect)，tooltip懸停之hoverPoint遺失而tooltip殘留舊內容 另Series.update之preserve清單與keepPoints條件、系列型別切換、responsive.rules切換等亦各有update與new不等價之處，詳見sgud/exp/experience.md

    ResizeObserver：Highcharts每建一圖(onload的Chart.setReflow，:36551-36559、:37262)即無條件以全域ResizeObserver新增一個偵測容器之偵測器，無解除機制，不論chart.reflow是否為false； 其回呼閉包持有圖物件，反覆重建時已destroy之圖殼物件隨次數累積(實測重建30次後存活Chart物件32個)；本組件以trackResizeObserver於建圖期間捕捉該偵測器，於下次重建前與組件銷毀時disconnect，存活圖物件不隨重建次數增長(捕捉後為2個)； 本組件恆給chart.reflow為false並自行以v-domresize同步尺寸，故該偵測器之回呼本來就什麼都不做，disconnect不影響行為

    容器尺寸同步：以w-component-vue之v-domresize(wsemi domDetect，ResizeObserver，並處理元素消失與重建)偵測，以與Highcharts相同之方式量測容器並與圖表目前尺寸比較，不一致時於繪製前同步圖表尺寸，取代Highcharts內建reflow(防抖100ms，連續拖拉時不跟隨)； 容器隱藏(寬或高為0)或尺寸與圖表一致時不重繪，options.chart.reflow給false則不同步，options.chart.width、height有給者該維度固定

isPropUnchanged(nv, ov) → {Boolean}

Description:

  • 判斷prop新舊值是否視為未變更，供watcher略過無實質變化之觸發

    父組件於模板以物件字面值傳入prop時(例如:options="{ series: [...] }")，每次重繪皆產生新物件(參照不同)，故內容相同時視為未變更； 新舊值為同一物件時，代表由deep watcher偵測到物件內部異動(例如push資料點)，視為已變更

trackResizeObserver(fn, list) → {*}

Description:

  • 執行fn期間收集其中建立之ResizeObserver實例，內部使用

    Highcharts(11.4.8)每建一圖，onload時由Chart.setReflow無條件以全域ResizeObserver建立一個監聽容器之偵測器，且無任何解除機制(highstock.src.js:36551-36559、呼叫處:37262)， 不論chart.reflow是否為false(本套件恆給false，該偵測器之回呼因此什麼都不做，純屬累積)； 其回呼閉包持有該圖物件，故反覆重建時，已destroy之圖殼物件(Chart)隨次數累積無法回收(實測重建30次後存活Chart物件32個，捕捉並disconnect後為2個)； 本函數於fn期間暫以包裝建構函數取代window.ResizeObserver記下所建立之實例，結束(含拋錯)即還原，呼叫端於圖表銷毀時對所收集之實例disconnect； 無ResizeObserver(例如伺服器端或舊瀏覽器)時直接執行fn，Highcharts改以window resize事件並於destroy時解除，無需處理
